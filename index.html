私本管理Amazon同期

Shihon Amazon Sync — a personal tool that reads the developer's own Amazon.co.jp order emails (read-only) and adds purchased books to a local book catalog.

プライバシーポリシー 利用規約

これは何か

Amazon.co.jp で買った本を、蔵書管理ソフト「私本管理Plus」へ登録し忘れないようにするための、 個人用の Windows ツールです。開発者本人が自分のパソコンで使うためのもので、一般には配布していません。

していること

  1. 利用者が手動で起動したときだけ、利用者自身の Gmail から Amazon.co.jp の注文確認メールとキャンセル通知を読みます（読み取り専用の権限）。
  2. メールから注文番号・商品名・ASIN（本ならISBN）・書影のURL・注文日を取り出します。
  3. 本だけを選び、利用者のパソコンにある蔵書データに未登録のものを、利用者が確認したうえで追記します。

していないこと

  • メールの送信・削除・ラベル変更などの書き込みはしません（その権限を持っていません）。
  • Amazon 関連以外のメールは検索しません。
  • 読み取った内容を、開発者や第三者のサーバーへ送りません（そもそもサーバーはありません）。
Amazon、Amazon.co.jp は Amazon.com, Inc. の、Gmail は Google LLC の商標です。本ツールはそれらの企業とは関係ありません。
