プライバシーポリシー

私本管理Amazon同期（Shihon Amazon Sync）／制定日 2026年10月27日

← アプリの説明利用規約

1. 対象

本ツールは開発者本人が自分のパソコンで使うための個人用ツールです。 このポリシーは、本ツールが Google のアカウントデータ（Gmail）をどのように扱うかを説明します。

2. アクセスするデータ

  • 権限: Gmail の読み取り専用権限（https://www.googleapis.com/auth/gmail.readonly）のみ。
  • 検索するメール: Amazon.co.jp の注文確認メール（auto-confirm@amazon.co.jp）と、キャンセル通知（order-update@amazon.co.jp の件名に「キャンセル」を含むもの）だけです。
  • 取り出す情報: 注文番号、商品名、ASIN（本の場合はISBN）、書影画像のURL、注文日。

3. 使い方と保存場所

  • 処理はすべて利用者自身のパソコン上で行います。開発者が運営するサーバーはなく、メールの内容をどこにも送信しません。
  • 取り出した情報のうち、本として登録したものは、利用者のパソコン上の蔵書管理ソフトのデータファイルに保存されます。 処理済みの注文番号・書名・処理日時も、二重登録を防ぐため同じパソコンに記録します。
  • メール本文そのものは保存しません。
  • 本の書誌情報（著者・出版社・ページ数など）を補うため、ISBN または書名だけを openBD と国立国会図書館サーチの公開APIに問い合わせます。メールの内容やアカウント情報は送りません。

4. 認証情報の扱い

Google から受け取る更新用トークンは、利用者のパソコンの Windows 資格情報マネージャーに保存し、ファイルや外部には置きません。

5. 第三者への提供

Google のアカウントデータを、販売・広告・第三者への提供・転送に使うことはありません。 人がメールを読むこともありません（利用者本人が自分の画面で確認する場合を除く）。

6. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールが Google API から受け取った情報の使用および他のアプリへの転送は、 限定使用（Limited Use）の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

7. アクセスの取り消し

本ツールへの Gmail のアクセス許可は、いつでも Google アカウントの「サードパーティ製のアプリとサービス」 から取り消せます。本ツール側でも取り消しの操作ができます。

8. 変更

このポリシーを変更する場合は、このページを更新し、制定日の下に改定日を記載します。

9. 問い合わせ

このページを公開している GitHub リポジトリの Issues からお願いします。
